# Petite Lueur PL 官方網站（前台）

此儲存庫收錄 Petite Lueur PL 日本・韓國代購網站的前台 HTML、樣式、互動與已核准公開的商品資訊快照。

- GitHub Pages：`https://saoririri.github.io/petite-lueur-pl/`（啟用後可瀏覽）
- 商品資料：首版 159 件已公開商品；動態更新仍透過原有 Google Apps Script 後端
- 訂單申請、Email 驗證、付款回報、Notion 同步、主購後台：保留在受保護的 Google Apps Script 後端，逐項驗收
- **禁止提交**：Notion API 金鑰、Apps Script 私密設定、客戶訂單個資、付款資料、OTP、管理員登入資訊
- 未經主購核准的新商品與圖片不得公開

正式切換前，請確認 `staticBridge=1` 後端連線、訂購、OTP、付款回報與行動裝置顯示都能正常運作。
